# public/

Files in this directory are served at the site root by Vite.
For example, `public/lithium-sea-hero.mp4` is reachable at `/lithium-sea-hero.mp4`.

## Required assets

- **`lithium-sea-hero.mp4`** — the hero background video.
  Drop the file directly into this directory with that exact filename.
  Recommended: H.264/MP4, ~1080p, muted/no audio track, kept under ~10 MB so it
  loads quickly. The page will work without it (the gradient background shows
  through), but the hero won't have motion until the file is in place.
